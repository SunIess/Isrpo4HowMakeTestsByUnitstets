# Isrpo4HowMakeTestsByUnitstets

## Цели и Задачи
Цель тестирования: проверить корректность работы функций вычисления площади и периметра прямоугольника (area и perimetr) с помощью модуля unittest, а также убедиться, что функции правильно обрабатывают граничные случаи (нулевые значения сторон). А также научиться пользоваться библиотекой unittests.
## Описание продукта 
Модель с функциями area и perimetr. Требования неотрицательные стороны, возврат числа.
## Область Тестирования 
Проверяются нулевые стороны квадрат произвольный прямоугольник.
## Стратегия тестирования
Функциональное тестирование, ручной расчет ожидаемых значения автоматизация через unittest/
## Критерии приемки 
Все тесты проходят(ок).
